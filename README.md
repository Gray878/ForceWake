# 不许睡强制闹钟 App

## 项目简介

不许睡（No Sleeping Allowed）是一款强制唤醒闹钟应用，通过任务机制和防作弊措施，确保用户彻底清醒并完成任务才能关闭闹铃。

- **开发平台**: HarmonyOS 原生开发
- **开发语言**: ArkTS
- **参考应用**: 使命闹钟

## 功能模块

### 1. 闹钟管理模块 (P1 - 核心功能)

- ✅ **闹钟列表展示**: 显示所有已设置的闹钟，包括时间、重复周期、任务绑定状态和开关状态。顶部显示距离下次响铃的时间。
- ⏳ **新增与编辑闹钟**: 提供时间滚轮选择器、单次/重复周期选择、音量设置、震动开关、以及任务绑定功能。
- ✅ **闹钟状态切换**: 用户可以通过列表页的开关快速启用或禁用任一闹钟。
- ⏳ **删除与暂停**: 支持删除闹钟。闹钟响起后，任务完成前不允许"小睡"（Snooze）。
- ⏳ **铃声和震动**: 允许用户从内置铃声库中选择闹铃声音。提供自定义音量调节和震动开关。

### 2. 强制任务系统 (P1 - 核心功能)

- ⏳ **任务选择界面**: 提供任务分类列表，支持选择和绑定一个或多个任务到单个闹钟。
- ⏳ **数学题任务**: 用户需在规定时间内，正确解答设置数量和难度的四则运算题。
- ⏳ **记忆游戏任务**: 用户需完成一个基于卡片匹配的记忆游戏。
- ⏳ **条形码/二维码任务**: 用户需使用摄像头扫描预先保存的条形码或二维码。
- ⏳ **拍照任务**: 用户需拍摄与预设图片相似的场景照片。
- ⏳ **摇晃任务**: 用户需剧烈摇晃设备，达到预设的次数或加速度阈值。

### 3. 强制唤醒机制与设置 (P1 - 核心功能)

- ⏳ **阻止关机/强停**: 防作弊功能。闹钟响铃且任务未完成期间，需申请鸿蒙系统高级权限。
- ⏳ **权限管理**: 集中管理后台运行、悬浮窗、阻止关机、摄像头、存储等权限。
- ⏳ **通用设置**: 提供默认任务难度、主题颜色、音量渐强等常规设置。

### 4. 附加与数据模块 (P2/P3 - 重要/附加功能)

- ⏳ **起床得分**: 根据任务完成速度、准时程度和任务难度计算"起床得分"。
- ⏳ **早晨感觉记录**: 完成任务后可记录当天早晨的感觉。
- ⏳ **睡眠提醒**: 提供睡眠时间提醒功能。
- ⏳ **数据报告**: 汇总用户起床时间、起床得分、任务完成统计等数据。
- ⏳ **问题反馈与关于**: 提供反馈入口和应用版本、开发者信息等"关于我们"页面。
