# 编译错误解决方案

本文档记录了在开发"不许睡强制闹钟"应用过程中遇到的编译错误及其解决方案。

## 错误列表

### 1. 对象字面量不能用作类型声明错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: Object literals cannot be used as type declarations (arkts-no-obj-literals-as-types)
At File: AlarmListPage.ets:13:25
```

**原因分析：**
在 ArkTS 中，不能直接在类型声明中使用对象字面量语法，必须使用接口（interface）或类型别名（type alias）。

**错误代码示例：**
```typescript
@State nextAlarmTime: { hours: number; minutes: number } | null = null;
```

**解决方案：**
1. 在 `Utils.ts` 中定义接口：
```typescript
export interface NextAlarmTime {
  hours: number;
  minutes: number;
}
```

2. 在 `AlarmListPage.ets` 中使用接口：
```typescript
import { Utils, NextAlarmTime } from '../common/Utils';

@State nextAlarmTime: NextAlarmTime | null = null;
```

**修改文件：**
- `entry/src/main/ets/common/Utils.ts`
- `entry/src/main/ets/pages/AlarmListPage.ets`

### 3. @Param 装饰器使用错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: The '@Param' decorator can only be used in a 'struct' decorated with '@ComponentV2'
At File: BottomNavBar.ets:6:4
```

**原因分析：**
在 ArkTS 中：
- `@Param` 装饰器只能在 `@ComponentV2` 装饰的结构体中使用
- 对于普通的 `@Component` 装饰的结构体，应该使用 `@Prop` 装饰器

**错误代码示例：**
```typescript
@Component
export struct BottomNavBar {
  @Param currentIndex: number = 0;
  @Param onTabChange: (index: number) => void = () => {};
}
```

**解决方案：**
将 `@Param` 改为 `@Prop`：
```typescript
@Component
export struct BottomNavBar {
  @Prop currentIndex: number = 0;
  onTabChange?: (index: number) => void;
}
```

**注意：**
- `@Prop` 用于父组件向子组件传递数据（单向）
- 函数类型应该使用可选属性（`?:`）
- 调用时需要传入完整的参数对象

**修改文件：**
- `entry/src/main/ets/components/BottomNavBar.ets`
- `entry/src/main/ets/pages/Index.ets`

### 4. 页面入口装饰器错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: A page configured in 'main_pages.json or build-profile.json5' must have one and only one '@Entry' decorator
At File: SleepPage.ets, MorningPage.ets, SettingsPage.ets, AddEditAlarmPage.ets, TaskSelectPage.ets, AlarmRingingPage.ets
```

**原因分析：**
- 在 `main_pages.json` 中配置的页面必须使用 `@Entry` 装饰器
- 但是这些页面不是独立入口，它们被 `Index.ets` 内部引用作为组件使用
- 只有 `Index.ets` 是真正的入口页面

**错误配置：**
```json
{
  "src": [
    "pages/Index",
    "pages/AlarmListPage",
    "pages/SleepPage",
    "pages/MorningPage",
    "pages/SettingsPage",
    "pages/AddEditAlarmPage",
    "pages/TaskSelectPage",
    "pages/AlarmRingingPage"
  ]
}
```

**解决方案：**
只保留真正的入口页面 `Index.ets`：
```json
{
  "src": [
    "pages/Index"
  ]
}
```

**说明：**
- `Index.ets` 是主入口，使用 `@Entry` 装饰器
- `AlarmListPage.ets` 也使用了 `@Entry`，因为它在主页面中被直接使用
- 其他页面作为组件被 `Index.ets` 引用，不需要 `@Entry` 装饰器
- 如果后续需要独立路由跳转，可以在 `main_pages.json` 中添加并添加 `@Entry` 装饰器

**修改文件：**
- `entry/src/main/resources/base/profile/main_pages.json`
- `entry/src/main/ets/pages/SleepPage.ets`
- `entry/src/main/ets/pages/MorningPage.ets`
- `entry/src/main/ets/pages/SettingsPage.ets`
- `entry/src/main/ets/pages/AddEditAlarmPage.ets`
- `entry/src/main/ets/pages/TaskSelectPage.ets`

### 5. null 和 undefined 类型不兼容错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: Type 'Alarm | null' is not assignable to type 'Alarm | undefined'.
Type 'null' is not assignable to type 'Alarm | undefined'.
At File: AlarmListPage.ets:105:11
```

**原因分析：**
在 ArkTS 中，`null` 和 `undefined` 是不同的类型：
- `null` 是一个值，表示空值
- `undefined` 表示未定义

当属性定义为 `Alarm | undefined` 时，不能直接传入 `Alarm | null` 类型。

**错误代码示例：**
```typescript
@State editingAlarm: Alarm | null = null;

// 在组件中使用
AddEditAlarmPage({
  alarm: this.editingAlarm,  // 类型不匹配
  ...
})
```

**解决方案：**
使用空值合并操作符 `??` 将 `null` 转换为 `undefined`：
```typescript
AddEditAlarmPage({
  alarm: this.editingAlarm ?? undefined,
  onClose: () => { ... },
  onSave: (alarm: Alarm) => { ... }
})
```

**修改文件：**
- `entry/src/main/ets/pages/AlarmListPage.ets`

### 6. @Param 装饰器在普通组件中使用错误（续）

**错误信息：**
```
ArkTS Compiler Error
Error Message: The '@Param' decorator can only be used in a 'struct' decorated with '@ComponentV2'.
At File: AddEditAlarmPage.ets:11:4
At File: TaskSelectPage.ets:9:4
```

**原因分析：**
与错误3相同，`@Param` 只能在 `@ComponentV2` 中使用。对于普通 `@Component`，应该：
- 使用 `@Prop` 传递简单数据
- 使用普通属性传递回调函数（可选）

**错误代码示例：**
```typescript
@Component
export struct AddEditAlarmPage {
  @Param alarm?: Alarm;  // 错误
  @Link onClose: () => void;  // 错误
}
```

**解决方案：**
将 `@Param` 改为 `@Prop`，将 `@Link` 改为普通可选属性：
```typescript
@Component
export struct AddEditAlarmPage {
  @Prop alarm?: Alarm;
  onClose?: () => void;
  onSave?: (alarm: Alarm) => void;
}
```

**注意：**
- `@Prop` 用于父组件向子组件传递数据（单向）
- 回调函数使用可选属性，并在使用时检查是否存在

**修改文件：**
- `entry/src/main/ets/pages/AddEditAlarmPage.ets`
- `entry/src/main/ets/pages/TaskSelectPage.ets`

### 7. TimePicker selected 参数类型错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: Type '{ hour: number; minute: number; }' is not assignable to type 'Date'.
Object literal may only specify known properties, and 'hour' does not exist in type 'Date'.
At File: AddEditAlarmPage.ets:120:27
```

**原因分析：**
`TimePicker` 组件的 `selected` 属性需要传入 `Date` 对象，而不是包含 `hour` 和 `minute` 的对象字面量。

**错误代码示例：**
```typescript
TimePicker({
  selected: { hour: this.hour, minute: this.minute }
})
```

**解决方案：**
创建一个 `Date` 对象并设置小时和分钟：
```typescript
TimePicker()
  .selected(this.createTimePickerDate())
  .onChange((value: TimePickerResult) => {
    this.hour = value.hour;
    this.minute = value.minute;
  })

// 辅助方法
private createTimePickerDate(): Date {
  const date = new Date();
  date.setHours(this.hour);
  date.setMinutes(this.minute);
  date.setSeconds(0);
  date.setMilliseconds(0);
  return date;
}
```

**修改文件：**
- `entry/src/main/ets/pages/AddEditAlarmPage.ets`

### 8. Color.Purple 不存在错误

**错误信息：**
```
ArkTS Compiler Error
Error Message: Property 'Purple' does not exist on type 'typeof Color'.
At File: TaskSelectPage.ets:241:31
```

**原因分析：**
HarmonyOS 的 `Color` 类可能不包含 `Purple` 常量。需要使用其他方式表示紫色。

**错误代码示例：**
```typescript
const colors: Record<TaskType, ResourceColor> = {
  [TaskType.SHAKE]: Color.Purple,  // 错误：Purple 不存在
  ...
};
```

**解决方案：**
使用十六进制颜色值代替：
```typescript
const colors: Record<TaskType, ResourceColor> = {
  [TaskType.SHAKE]: '#AF52DE', // Purple color (十六进制)
  ...
};
```

或者使用其他已存在的颜色常量：
```typescript
// 检查可用的颜色常量
[TaskType.SHAKE]: Color.Magenta, // 如果存在的话
```

**修改文件：**
- `entry/src/main/ets/pages/TaskSelectPage.ets`

## 修复总结（更新）

### 已修复的问题

1. ✅ **类型声明问题**：使用接口替代对象字面量类型
2. ✅ **Router 导入问题**：暂时移除，后续实现正确的路由功能
3. ✅ **装饰器使用问题（@Param）**：改为 `@Prop` 或普通属性
4. ✅ **页面入口配置问题**：只保留真正的入口页面
5. ✅ **null 和 undefined 类型不兼容**：使用 `??` 操作符转换
6. ✅ **TimePicker 参数类型错误**：使用 Date 对象而不是对象字面量
7. ✅ **Color.Purple 不存在**：使用十六进制颜色值

### 常见错误模式

1. **装饰器混用**：
   - `@Component` → 使用 `@Prop` 和普通属性
   - `@ComponentV2` → 可以使用 `@Param` 和 `@Link`

2. **类型兼容性**：
   - `null` 和 `undefined` 是不同的类型，需要显式转换
   - 对象字面量不能直接用于类型声明

3. **API 使用**：
   - 仔细查阅 HarmonyOS 官方文档确认 API 参数类型
   - 某些常量可能不存在，使用替代方案
